# smallsh
This is the small shell portfolio project for Oregon State University's CS 374 (Operating Systems I) course. Unless otherwise specified via comments, all code was written by Kai Sherman.
## Installation
This project depends on Linux or a Linux environment like Ubuntu via WSL. To run:
```
$ git clone https://github.com/Kaishermy/smallsh.git
$ cd smallsh
$ gcc -std=gnu99 shermkai_assignment4.c -o smallsh
$ ./smallsh
```
